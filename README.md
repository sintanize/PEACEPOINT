# PeacePoint 🌿

PeacePoint is a mental wellness app designed to help users:
- Calm during stressful moments
- Track triggers and emotions
- Journal thoughts and progress
- Build personal coping strategies

## Version
1.0

## Main Features
- Calm Now breathing exercises
- Trigger Tracker
- Private Journal
- Progress Dashboard
- Safety Plan
- Hope Box

## Goal
Help people find a peaceful point during difficult moments.
